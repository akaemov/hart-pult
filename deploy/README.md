# Доступ к серверу

`pult.pub` — открытая часть ключа, которым пульт разворачивается на сервере.
Открытый ключ на то и открытый: сам по себе он доступа не даёт, вход возможен
только с закрытой частью, а она лежит на машине разработчика.

Лежит в репозитории по одной причине: в VNC-консоли сервера нельзя вставить
текст, а набирать строку base64 руками — гарантированная опечатка. Сервер
забирает ключ сам:

```
mkdir -p ~/.ssh && curl -fsSL https://raw.githubusercontent.com/akaemov/hart-pult/main/deploy/pult.pub >> ~/.ssh/authorized_keys && chmod 700 ~/.ssh && chmod 600 ~/.ssh/authorized_keys && echo OK
```

После настройки сервера файл можно удалить — доступ от этого не изменится.
